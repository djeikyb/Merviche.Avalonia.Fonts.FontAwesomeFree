An example of how to package custom fonts for Avalonia, using the Font
Awesome Free fonts.

It's likely not ideal to bundle several entire icon fonts in an app.
Long term, it's probably better to bundle just the icons that are
actually used. But as a tactic early on in a project, it's quite nice.
